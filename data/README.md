# Data notes

These are aggregate exports from the workbook's saved PivotTable results. They are included so the portfolio analysis runs without access to the original workbook.

- `category_sales.csv`: all 11 displayed categories.
- `top10_city_sales.csv`: only the ten rows displayed in the workbook's Top 10 city PivotTable.

The `sales_source_units` field is intentionally not labeled as dollars or any other currency. The workbook summaries do not establish the currency or reporting dates. The original workbook, source rows, customer names, and employee names are not included.

Before making this repository public, confirm that you have permission to share these aggregate business figures. Replace them with approved data if needed.
